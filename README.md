## Project Title
**Graph Search and Profiling System using BFS and DFS**

## Project Description
This project demonstrates graph traversal using Breadth-First Search (BFS) and Depth-First Search (DFS). The graph is represented using Python data structures and NetworkX. BFS uses a queue, while DFS uses a stack. The system maintains visited nodes and parent information to reconstruct the search path. Execution time is measured using Python's `timeit.repeat()` function.
